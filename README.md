# grid2cloud-preview

Isolated **development preview** of the Cloud2Grid React site, for review alongside the official
application. Not official, not a release.

- Preview: https://hinox13.github.io/grid2cloud-preview/ (served from the `gh-pages` branch, which
  holds only the compiled static site, its frozen data, licences and attribution).
- Earlier prototype kept for comparison: https://hinox13.github.io/grid2cloud-preview/v1/
- Official application: https://cloud2grid.streamlit.app/ · research and source: https://github.com/hinox13/grid2cloud
- This repository contains no source code and no research data; it is rebuilt from the development
  source by a staging script with publication checks (allowed files, data hashes against the published
  bundles, secret and private-path scans).
