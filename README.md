# grid2cloud-preview

Isolated **development preview** of the Cloud2Grid React website, for review before a release. Not official,
not a release.

- Preview: https://hinox13.github.io/grid2cloud-preview/ (served from the `gh-pages` branch, which holds only the compiled static site, its
  frozen data, licences and attribution).
- Earlier prototype kept for comparison: https://hinox13.github.io/grid2cloud-preview/v1/
- **Official Cloud2Grid application:** the React website, https://hinox13.github.io/grid2cloud/ (the guided experience and the
  Scientific Explorer).
- **Source, models and reproducibility:** https://github.com/hinox13/grid2cloud
- **Original Streamlit Explorer:** https://cloud2grid.streamlit.app/, kept as an optional alternative; not the
  official application.
- This repository contains no source code and no research data. It is rebuilt from the development source by
  a staging script with publication checks (allowed files, data hashes against the published bundles, secret
  and private-path scans).
